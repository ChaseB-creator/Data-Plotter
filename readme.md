# Interactive Data Plotter

This is a project where the user can interact with a dynamic data visualizer built using Python, HTML, CSS, and JavaScript.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Obtain the web address.

2. Current Python version will need to be installed on the user's device/machine (python 3.14 currently); this is needed in order to compile the backend script for the website.

Instructions for using the software:

1. The user will start on a page with the name "Interactive Data Plotter" at the top of the website.
2. Scrolling down and looking at the contents of the website, the user will see input boxes with x values, y values, and the ability to name the x-axis along with the ability to name the y-axis, finally also with the ability to name the graph and change the graph type.
3. Clicking on the boxes allows for the user to change the values.
4. Once all information is filled out, the user can click "Generate Graph", in which then a visual representation of the data they gave will be displayed on the bottom of the website.
5. In order to restart the page, the user can either reload the page or simply hit the "Reset" button to clear the current graph info.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* You will need all Web development fundamentals installed (HTML, CSS, JavaScript), along with the current version of Python, along with the Python framework used for this website (Flask).
